# Rasuljon ortoped lid — operator varag'i

Meta (Instagram/Facebook) lid formasi to'ldirayotgan **"Rasuljon ortoped lid"** Google jadvali ichida
operator uchun qulay **Operator**, **Bugun** va **Statistika** varaqlarini yasaydi.
Formadan keladigan xom varaqqa tegilmaydi, shuning uchun integratsiya buzilmaydi.

## O'rnatish (1 marta, jadval egasi)
1. Jadvalni oching → **Расширения → Apps Script**.
2. Bor kodni o'chirib, `Code.gs` dagi kodni to'liq qo'ying → 💾 saqlang.
3. Yuqoridagi ro'yxatdan **`sozlash`** ni tanlab **▶ Выполнить** → ruxsat bering
   ("Дополнительные настройки → Перейти на страницу" orqali).
4. Jadvalga qayting — tayyor. Yangi lidlar har 5 daqiqada o'zi tushadi,
   darhol kerak bo'lsa menyuda **🦴 Lidlar → Yangi lidlarni hozir olish**.

Boshqa xodimlarga oddiy **Редактор** dostupi bersangiz yetarli.

## Operator varag'i
| Ko'k ustunlar (formadan avtomatik) | To'q sariq ustunlar (operator to'ldiradi) |
|---|---|
| №, Lid vaqti, Bemor ismi, Telefon, Manzil, Shikoyat, Og'riq qachondan, MRT/rentgen, Bemor: qachon kelmoqchi, Manba (Instagram/Facebook + reklama) | **Holat**, **📞 Qachon bog'lanish**, **🏥 Qachon keladi**, **Soat**, **Izoh** |

- Holat: Yangi · Javob bermadi · Qayta bog'lanish · O'ylab ko'radi · Qabulga yozildi · Keldi · Kelmadi · Rad etdi · Noto'g'ri raqam
- "Javob bermadi" tanlansa, qo'ng'iroq sanasi avtomatik **ertaga** qo'yiladi.
- Test lidlar (`<test lead`) va takrorlar o'tkazib yuboriladi; `p:+998…` kabi prefikslar, `_` belgilar tozalanadi.

**Ranglar:** 🟨 bugun qo'ng'iroq · 🟥 qo'ng'iroq kuni o'tib ketgan · 🟩 bugun keladi · 🔵 hali bog'lanilmagan

## Bugun varag'i
Bugun keladiganlar (soat bo'yicha), bugun qo'ng'iroq qilinadiganlar va hali bog'lanilmagan yangi lidlar.

## Statistika
Jami / bugun / shu oy lidlar, konversiya, holat va manba (Instagram / Facebook) bo'yicha sonlar.
